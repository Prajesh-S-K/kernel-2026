      04 / HANDS-FREE SETUP

      No selection buttons.
      Just you.

      A helper trains two gestures once. The only physical control is one enable button that permits or disables control; it never selects, pauses or resumes.

      INTERACTION MODELEGACY SWITCH MODEAll gesture values are START values, unvalidated.
      HELPER SETUPHELPER ONLY

        Wire the button between the enable GPIO and GND. Permission is never saved: it is off after every restart and fault, and permitting never resumes control.

        Only qualify this if no switch or button can be used; control then cannot be disabled by an input.

        Switches off dwell clicks, drag and scrolling and bounds the pointer step, for a safe first look on real hardware. Turning it on or off pauses control; resume afterwards. It is off after every restart.

        Legacy mode keeps the earlier physical-switch behaviour. It never turns on by itself and hands-free is never turned on silently either.
